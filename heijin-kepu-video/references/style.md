# 视觉规范（黑金科普风）

一句话：**像一本深色封面的科学杂志在动**——安静、克制、有文献感，靠细线条、留白和金色点睛，而不是靠花哨特效。

## 颜色（只用这些，定义在 `src/theme.ts` 的 `COLORS`）

| 名称 | 色值 | 用途 |
|---|---|---|
| `bg` | #0b0b0d | 背景（框架已画好，不用管） |
| `cream` | #ece2cf | 主线条、主文字、主体图形 |
| `creamDim` | #b9ad97 | 坐标轴、次要文字、引线 |
| `muted` | #6f685c | 最弱的注释、日期范围 |
| `gold` / `goldBright` | #d4af6a / #e8c98a | 强调：关键数字、高亮的那一部分、结论 |
| `red` / `redBright` | #c2685a / #e0705f | 反面、错误、危险、弹孔、损失 |
| `panel` | #141416 | 卡片、标签的底色 |

- 一个画面里**金色只给最重要的一样东西**。其他都是奶油白/暗白。
- 红色只在「不好的」东西上出现。
- 不要用纯白 #fff、纯黑以外的饱和色（蓝、绿、紫），不要渐变彩虹。
- 需要「夜晚/天空/海洋/历史」氛围时，用 `bg: "night"`（偏蓝的暗底），其余元素颜色不变。
- 填充色用低明度的暗色（如 `#2a2e36`、`#3a3324`），线条用 cream/gold，像版画。

## 字体

- 正文、数字、标注：宋体衬线（`SERIF`，思源宋体）。
- 封面、片尾、特别大的标题：得意黑（`TITLE_FONT`）。
- 字号（1920×1080 画布）：大数字 120–180，场景标题/年份 64–80，图中标注 26–34，坐标刻度 20–22，最小注释 17–20。**不要小于 17。**

## 版式

- 画布 1920×1080，四周留 96px 安全边距。
- **左上角**：`Kicker`（年份/地点/场景名）。**右上角**：`SourceNote`（文献出处 + 红印章）。两者都是可选的，但同一场不要再放别的东西进这两个角。
- **画面中央 y 140–920**：主体（图表、示意图、点阵、剪影）。常见是左右两栏：左边大数字或剪影，右边图表或列表。
- **底部 y > 940**：字幕区，不要放任何东西。
- 每场一个视觉焦点；元素少而大，宁可空，不要挤。

## 动效节奏

- 元素**跟着字幕出现**：第 k 句字幕出现时（`cue(k)`），画面同步出现这句话说的那个东西。
- 出现方式：淡入 + 轻微上移（`Fade rise={12}`）、描线（`DrawPath`）、数字滚动（`BigNumber`）、逐个点亮（`IconGrid`）、粒子聚合（`ParticleText`）。
- 时长：淡入 10–18 帧，描线 25–60 帧，数字滚动 30–40 帧。缓动用 `ease`，不要弹跳、不要旋转飞入。
- 持续的小动作让画面「活着」：缓慢漂浮（`Math.sin(frame / 25) * 4`）、微弱呼吸光圈、扫描线闪烁。幅度要小。
- 强调已经出现的东西：变金色、其他变暗（`IconGrid` 的 `highlight`、`NumberList` 的 `dimOld`）、加一个圈或箭头。
- 一场里新元素一般 2–4 个，不要一次全部出现。
